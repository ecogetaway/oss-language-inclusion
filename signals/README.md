# Signals

This folder captures synthesized observations from the ecosystem.

- `maintainer-signals.md` -> perspectives from maintainers  
- `contributor-signals.md` -> perspectives from language contributors  
- `signals-overview.md` -> combined summary of observed patterns  

These documents are derived from case studies and ongoing input.

They are **research notes for this repository**. They are not a file other
projects copy.

A draft **root declaration file** that other projects *may* adopt
(`i18n-signals.yml`) is specified under [`spec/i18n-signals.md`](../spec/i18n-signals.md),
with examples in [`spec/examples/`](../spec/examples/). Same word, two roles.
