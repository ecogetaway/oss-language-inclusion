## What Happened
A contributor submitted Korean i18n support for the project's website as a single pull request of 349 files and more than 30,000 added lines. Three days later a repository collaborator asked for it to be broken "into smaller pieces with descriptions as to why these changes were made", explaining that at its size it was very difficult to review. The contributor's last commit was made the day before that request, and no further activity followed. The stale bot marked the pull request inactive and then closed it.

## Maintainer Response
A clear, constructive scoping request on day three.

## Why This Matters
Review surface is itself a barrier for language contributions. A whole-site translation arriving as one very large change is hard for any reviewer to assess, and harder still for one who does not read the language. The request to split it was reasonable; the case shows the value of telling contributors up front how to scope a translation (for example, one section or package per pull request).
